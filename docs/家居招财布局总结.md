# 家居招财布局总结

> 以八卦九宫、八宅、六爻卦象三套体系交叉整合，取自 10 份公开资料（文末附出处）。
> 用法：**先清 → 再定 → 后催**。顺序反了，摆再多东西都是白花钱。

---

## 0. 一句话总纲

**财位不是"放东西的地方"，是"气能停下来的地方"。**
所以第一动作永远是清杂物、通光、通风；第二动作是找对位置；第三动作才是摆件。三件事的权重约为 **6 : 3 : 1**。

## 2. 找财位：五套体系，从粗到细

### 2.1 明财位（30 秒能定位，先做这个）

看**大门开口位置**，取客厅对角线：

- 大门开在**左边** → 明财位在**右侧对角线顶端**
- 大门开在**右边** → 明财位在**左侧对角线顶端**
- 大门开在**正中** → 左右两条对角线顶端都算

这是全家"流动财"的聚点，也是最容易被快递盒、旧书、行李箱占掉的地方。

### 2.2 暗财位（按宅卦，八宅四吉方）

八宅把每个宅子分出四吉方：**生气 → 天医 → 延年 → 伏位**。财位优先取**生气方**，其次**天医方**。

| 宅卦（坐向） | 四吉方（含财位） |
|---|---|
| 坎宅（坐北朝南） | 东南、正南、正东、正北 |
| 坤宅（坐西南朝东北） | 东北、西北、正西、正南 |
| 震宅（坐东朝西） | 正南、正北、东南、正东 |
| 巽宅（坐东南朝西北） | 正北、正东、正南、东南 |
| 乾宅（坐西北朝东南） | 西南、正西、西北、正北 |
| 兑宅（坐西朝东） | 西北、西南、东北、正西 |
| 艮宅（坐东北朝西南） | 西南、西北、正西、东北 |
| 离宅（坐南朝北） | 正东、正北、东南、正南 |

> 坐向判定：人站在屋内、**面向大门**，面朝的方向为"向"，背后为"坐"。用罗盘/指南针校正。

### 2.3 个人财位（命卦生气方，最贴身）

**命卦算法**：出生年份后两位相加 → 加到个位 → 男用 **11 减**、女用 **4 加**（结果超过 9 再相加）→ 得数对应八卦。得 5：男变坤、女变艮。

| 得数 | 1 坎 | 2 坤 | 3 震 | 4 巽 | 6 乾 | 7 兑 | 8 艮 | 9 离 |
|---|---|---|---|---|---|---|---|---|
| 命卦 | 坎命 | 坤命 | 震命 | 巽命 | 乾命 | 兑命 | 艮命 | 离命 |
| **生气财位** | 东南 | 东北 | 正南 | 正北 | 正西 | 西北 | 西南 | 正东 |
| 钱从哪来 | 信息差、咨询、教育 | 积累、实业、长期投资 | 行动、销售、自媒体 | 脑力、中介、策划 | 资本、管理、权威 | 高层决策、高端服务 | 服务、照顾需求 | 干了再说、执行 |

**八命财位对应的摆件五行**：

- 坎命（财位东南·木）：木雕、木船、发财树、竹子 + 小型流水摆件
- 坤命（财位东北·土）：粗陶、石头、黄水晶、方形物件、陶缸存硬币
- 震命（财位正南·火）：红色水晶球、红蜡烛、红罩台灯、三角形摆件
- 巽命（财位正北·水）：鱼缸、流水摆件、黑曜石、水培富贵竹
- 乾命（财位正西·金）：铜/银/不锈钢、白水晶球、圆形金属钟、金属地球仪
- 兑命（财位西北·金）：同上，加白色装饰、银质器皿、金属铃铛
- 艮命（财位西南·土）：陶瓷、石头、黄色调、成对存钱罐（坤主双）
- 离命（财位正东·木）：大叶绿植 + 木雕马（马=离火=奔跑=执行）

### 2.4 流年财位（2026 丙午年）

- **正东 = 八白左辅 = 正财位**（工资、主业、实业、置产）
- **正北 = 六白武曲 = 偏财位**（投资、副业、奖金、意外之财）
- **东南 = 九紫右弼 = 喜庆位**（人缘、贵人、间接助财）

流年位每年立春（2 月 4 日前后）换一次，2026 年从 2026-02-04 到 2027-02-03 有效。

### 2.5 卦象财位（六爻，最细）

六爻里财位的核心是**妻财爻**：

1. 起卦（铜钱六爻 / 时间起卦 / 数字起卦）
2. 找**妻财爻**落在哪一爻、哪一宫
3. 按该宫的八卦方位落到实际房间
4. 看妻财爻旺衰：旺 → 该方位可催；空、破、墓 → 先化解再催

常用对应关系（来自抓取资料）：

| 财位类型 | 对应卦 | 催旺重点 |
|---|---|---|
| 正财位 | 坤、艮 | 稳定收入、事业财 |
| 偏财位 | 震、兑 | 投资、意外之财 |
| 暗财位 | 坎、离 | 隐性收入、贵人带财 |
| 流财位 | 巽、乾 | 商贸、流动财 |

## 3. 财位三要三忌（这一段决定成败）

### 三要

**① 干净**
- 财位堆杂物 = 财库堆垃圾。旧报纸、旧书、旧衣、快递盒、坏电器，全清。
- 一周一扫，比摆什么摆件都管用。
- 空着都比堆着强：空则气能流动。

**② 明亮**
- 自然光优先；照不到就加**暖光**（落地灯 / 壁灯 / 充电感应灯）。
- 灯不闪、不坏；坏了立刻换。
- 财位放一盏 24 小时常亮的小夜灯，是最便宜的催财手段。

**③ 有活物**
- 鱼：单数（1/3/5/7/9），红或金，金鱼最皮实；缸 45–60cm 即可；死鱼立刻捞；水浑 = 财源浑。
- 绿植：**大叶**为主（发财树、金钱树、龟背竹、天堂鸟、幸福树）；**拒绝仙人掌、针叶、带刺**；枯叶立刻剪，死株立刻换。
- 会动的东西：音乐盒、钟摆、流水摆件、水车——让气的循环不停。

### 三忌

**① 不压**
- 上方不能有横梁（横梁压财 = 钱被压着出不来）；有就吊顶包住，或两端挂五帝钱。
- 不能压重物：钢琴、大书柜、实木大茶几、床。
- 窗外有空调外机正压，也算压 → 拉窗帘。

**② 不对门**
- 财位正对大门 = 穿堂风破财，气没聚就被冲散。
- 化解：大门与财位之间加**半高隔断**或磨砂屏风——是"缓冲"，不是封死。
- 财位正对卫生间门：大凶，挂门帘（门帘颜色按财位五行选）。
- 财位正对卧室门：气跟着人跑，花钱大手大脚的人住那间 = 财位在养提款机。

**③ 不靠卫**
- 财位背后那堵墙的另一面若是卫生间，等于财位被污水之气泡着。
- 化解：贴墙放一排**粗盐**（每月换一次），或墙面挂**大山画**（山=土，土克水）。

## 4. 按房间布置

### 大门 / 玄关（纳气口）
- 门口整洁、无杂物、灯亮；鞋柜有门，鞋不外露。
- "进户见土"：玄关地面用陶土砖 / 天然石材，财基稳。
- 忌大门一开直看到底（穿堂煞）→ 屏风 / 泰山石敢当化解。
- 门对门、门对楼梯、门对电梯，都属于"气冲"，加玄关柜或门帘缓冲。

### 客厅（全家共享财位）
- 明财位在这里，优先布置。
- 可放鱼缸、水晶阵、聚宝盆、流水摆件（不干扰睡眠，展示型财位）。
- 沙发背后要有实墙（有靠山）；沙发不压梁。
- 灯光暖黄，忌大面积冷白。

### 卧室（24 小时泡在财位里）
- 若财位落在卧室：放绿植 + 暖光灯，**不放鱼缸**（水气扰睡眠）。
- 床不要压在财位上（人压财 = 钱来得辛苦）；床头靠财位方向的墙可以。
- 床头不靠窗、不对镜、不压梁。

### 厨房（食禄 / 财库）
- 灶台后方必须是实墙，不能悬空。
- 灶（火）与水池（水）不直线对冲，用 L 型布局形成相生。
- 厨房保持干净——厨房压煞，干净厨房本身助财。
- 米缸常满，象征"食禄不断"。

### 卫生间（漏财口）
- 保持干燥、通风、门常关、马桶盖常闭。
- 卫生间不压中宫、不压财位；正北（2026 偏财位）有卫生间尤其要注意。
- 漏水 = 漏财，龙头滴漏立刻修。

### 阳台 / 窗
- 窗户不多不少：太多阳气过盛财难聚，太少阴暗阴气重。
- 阳台不堆杂物，不种带刺植物。
- 落地窗穿堂煞 → 屏风 / 泰山石敢当。

### 书房 / 办公桌
- 书桌坐向：背实墙、面开阔；不背门、不面壁太近。
- 桌面"小财位"：桌子对应你财位方向的那一角，放小绿植 + 小台灯。
- 2026 年东北（四绿文昌）适合做书房 / 决策区。

**通用招财件**：
- **五帝钱**：挂财位附近墙面 / 门楣，化煞兼招财。

- **貔貅**：头朝**窗外或门外**（吃外面的财吐给家里）；定期清洗，脏了不灵。
- **三足金蟾**：头朝**门内**（吐财入宅），别朝外。
- **财神**：武财神（关公）面朝大门镇宅聚财；文财神（范蠡）背靠实墙、面向客厅。
- **水景**：水要流动、要干净、面积不超过财位空间的 1/10；水流方向**朝内**。

## 9. 常见误区（做了反而破财）

1. **财位放仙人掌 / 带刺植物** → 钱来了被扎跑。
2. **鱼缸过大** → 水气反压财位，缸 45–60cm 足够。
3. **财位堆"招财物"** → 器物太多 = 堵气，少而精才对。
4. **只摆不管** → 枯叶、死鱼、落灰的貔貅，全是反效果。
5. **2026 正东放鱼缸** → 八白属土，土克水，反损财。
6. **2026 正南动土装修** → 五黄位，全年最凶，忌敲打。
7. **貔貅头朝屋内** → 吃自家的财；金蟾头朝门外 → 吐财出去。
8. **财位正对卫生间门不处理** → 污水气直冲，赚的钱花在治病和麻烦上。
